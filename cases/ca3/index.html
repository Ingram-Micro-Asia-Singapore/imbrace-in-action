How it works

Put the answer and its working together

  1. Ask in plain words

    Choose the sales analyst in InsightsIQ, iMBrace's chat workspace, and ask for a figure or chart.

    See screen 1

  2. Check the source records

    A FlowOps workflow reads DataIQ, iMBrace's records board, checks each row and calculates the totals.

    See screen 5

  3. See the answer and its working

    The analyst quotes the calculated values. A regional chart repeats its values in the answer text.

    See screen 2

  4. Give finance a clear correction

    The analyst names a row that needs correction and marks the remaining total as incomplete.

    See screen 4
