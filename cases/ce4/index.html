    4How it's built

    What was built in iMBrace

    Data

    Nine DataIQ boards:

    • Source boards: the CRM, WhatsApp, mailbox, and Facebook and Instagram exports, each brought in with DataIQ Board Import and left as exported. A fifth source board holds web-chat visitors.
    • Customer Order History: each order's customer, linking basis, amount and status.
    • Customer 360: one record per customer, with name, email, phone, channels, source records, where each fact came from, a timeline, and Order count and Order total. These two are rollups through a DataIQ relation to the order history.
    • Customer Match Review and Customer Consolidation Requests.

    Logic

    1. Each export is imported with the gear menu's Import: upload, map columns by name, confirm.
    2. A person adds a record on Customer Consolidation Requests. A board automation starts the "Consolidate Customer Records" flow, built in FlowOps.
    3. Code cleans the data: phones to international format, emails to lower case, names turned round.
    4. Code matches records on shared email or phone and builds one Customer 360 record per customer, recording the source of every fact. No AI is involved.
    5. Records with a similar name but no shared email or phone stay separate. Weaker matches go to Customer Match Review.
    6. A steward edits the review record, sets "Same person" and presses SAVE. A board automation applies it on the next run.
    7. Code links orders to customers.

    AI setup

    One AgentIQ agent, the Customer 360 Assistant, on deepseek.v3.2. It has one read-only skill, "Look Up a Customer 360 Record", a FlowOps flow that returns facts with their sources. Its rules say to call the skill on every customer question. It cannot merge or edit records.

    How people reach it

    Staff ask in InsightsIQ and work in DataIQ boards.
