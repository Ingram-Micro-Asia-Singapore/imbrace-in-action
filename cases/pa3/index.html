The same workflow reads the purchase order, asks about an unclear line and waits for the recorded decisions. It then creates the approved sales order on the demo ERP board.

    4How it's built

    What was built in iMBrace

    Data

    • DocIQ model Customer Purchase Order, with its board: customer name, PO number, PO and delivery dates, currency, line count, then customer SKU, description, quantity and unit price per line, and order total.
    • DataIQ reference boards: Item Master (SKU, description, price, stock, substitute SKU), Customer Accounts, and Customer Item Terms (each customer's own item code and contract price).
    • DataIQ working boards: Questions to Customers, Customer Replies, Order Desk Decisions and ERP Sales Orders. All four are demo boards.

    Logic

    1. A PO is dropped into DocIQ. AI picks the model and reads the values with confidence.
    2. A board automation starts the pipeline, built in FlowOps.
    3. Code checks confidence and the order total, finds the customer, maps each line to our item, prices it (contract or list), checks stock and looks for duplicates.
    4. An unclear line becomes a lettered question on Questions to Customers. The run pauses with FlowOps' Approval step.
    5. The reply typed on Customer Replies resumes the same run. AI reads it; code accepts only an option that was offered.
    6. The order is held for the order desk. A decision on Order Desk Decisions names the PO, customer and exact version.
    7. Code checks the decision and writes one sales order to ERP Sales Orders. A resent PO is marked duplicate.

    Two more board automations start the reply and decision workflows.

    AI setup

    DocIQ's own document reader extracts the PO. One agent, Order Desk Assistant, created in AgentIQ on DeepSeek V3.2 with temperature 0 and no skills or knowledge, reads the customer's reply. It is called from an AI step inside the pipeline.

    How people reach it

    Staff drop the PO onto the DocIQ drop zone. Replies and decisions are typed into DataIQ forms.
